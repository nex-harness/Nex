| D11 | Replay is script-driven     | decided (changes the original plan)   | The original plan replayed recorded inbound frames. Inbound frames carry agent-assigned session ids, so they cannot be re-sent byte for byte. `replay-agent.mjs` re-runs the host script and diffs normalized output. Consequence: replay needs a scriptable host; the Go `nex-trace` tool is now optional.                                                                                |
| D12 | Delta frame batching        | decided (observed)                    | The agent batches conversation deltas on a 30 ms timer (`flushWindowMs`), so frame boundaries vary run to run. Replay compares the flattened delta stream and enforces frame contiguity. Frame boundaries and ordinals are covered by the wire vector tests, not by traces.                                                                                                                |
| D13 | Concurrent telemetry lane   | decided (observed)                    | `session_title` model telemetry interleaves non-deterministically with the main stream (1 of 5 runs). Compared as its own ordered lane. Any further lane needs the same level of evidence.                                                                                                                                                                                                 |
| D14 | Prefer mature Go libraries  | decided (user 2026-10-10)             | When a mature open-source Go library already implements a protocol or format we need (e.g. OpenAI Responses / Anthropic Messages / SSE / JSON-RPC), prefer it over hand-writing a parser. Hand-rolled code is reserved for behavior we must match byte-for-byte (v4 wire, envelope, frame) or that no library covers. Record the library choice and version in the row that introduces it. |

## Library selections (D14 consequence)

| Concern                        | Library                                                      | Version pinned             | Why                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------ | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| SQLite                         | `modernc.org/sqlite`                                         | v1.39.1                    | D3; no cgo; crosscheck green                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Process tree (Unix)            | stdlib `syscall` + `os/exec` (`Setpgid`, negative-pgid kill) | —                          | small enough that a library is overkill                                                                                                                                                                                                                                                                                                                                                                                                          |
| Process tree (Windows)         | `golang.org/x/sys/windows` Job Objects                       | (as in go.mod)             | official extension                                                                                                                                                                                                                                                                                                                                                                                                                               |
| WebSocket client (Phase 2)     | `github.com/coder/websocket`                                 | chosen when Phase 2 starts | context-aware, no global state; per phase-2 doc                                                                                                                                                                                                                                                                                                                                                                                                  |
| OpenAI Responses stream        | `github.com/openai/openai-go`                                | v1.12.0                    | Official Stainless SDK. Spike (`model-library-spike.md`): 20/20 fixtures pass through its decoder; `ResponseStreamEventUnion` covers our closed event set. We keep `internal/modelclient/sse.go` as the framing layer because the SDK's SSE aborts on a top-level `"error": null` (R1); SDK is used for request construction and per-event typed decoding. `WithMaxRetries(0)` mandatory so the SDK retry doesn't double-count ours.             |
| Anthropic Messages stream      | `github.com/anthropics/anthropic-sdk-go`                     | v1.80.0                    | Official Stainless SDK. Spike: 20/20 fixtures pass. Its `Stream.Next` switches on the SSE `event:` name with no default branch (R4), so we branch on the JSON `type` field ourselves. Same `WithMaxRetries(0)` rule.                                                                                                                                                                                                                             |
| Rejected: community OpenAI SDK | `github.com/sashabaranov/go-openai` v1.43.0                  | —                          | Its stream reader discards the SSE `event:` field (chat-completions framing), scoring 17/20 on our fixtures vs 20/20 for both official SDKs. Not a swap, a downgrade.                                                                                                                                                                                                                                                                            |
| Generic SSE                    | (kept hand-rolled) `internal/modelclient/sse.go`             | —                          | Already passes 20/20 fixtures + fuzz; both vendor SDKs' SSE layers showed failure modes we cannot accept (R1, R4). A future swap must demonstrate equal or better coverage on the same fixtures.                                                                                                                                                                                                                                                 |
| OpenAI chat-completions stream | (kept hand-rolled) `internal/adapters/model/openai/`         | —                          | Built before D14; passes 20/20 fixtures, 106 failure-classifier vectors, scenario replays S01–S05+S13 and 14 held-out, plus the live deepseek-flash run. Migrating to `openai-go`'s chat stream would replace ~500 lines of code that already carry that evidence, and the SDK's retry would need `WithMaxRetries(0)` anyway. Not migrating. Revisit if the wire format shifts upstream or a fixture catches a bug the SDK would have prevented. |
